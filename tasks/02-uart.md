## 实现内容

- RX 输入 uart_rxd 先经两级寄存器同步，空闲为高。起始沿后约半位检查仍低，然后每隔 434 拍在位中心依次采 bit 0 至 bit 7，检查停止位。
- 每收到合法字节，rx_data 同时给出该值，rx_valid 拉高一个 clk 周期。停止位错误丢弃字节并等待线路高后再接下一起始位。
- TX 空闲时 uart_txd=1、tx_ready=1。tx_valid && tx_ready 的上升沿锁存 tx_data，随后发送起始位、8 个数据位和停止位，各位 434 拍。完整停止位结束后恢复 ready。
- TX 在发送中保持当前锁存字节，ready=0。上游可以等待到 ready 再传下一字节。
- 复位按公共约定，尤其是 TX 复位空闲高。计数器选足够位宽，用 clk 与计数实现串口节拍。

## 独立验证与交付

在 testbench 中驱动串行电平，把 TX 连接到 RX，依次发送 00、55、AA、FF，核对数据和接收次数。另用独立串行激励检查 RX 位序，按 434 拍核对 TX 起始位和停止位，避免同一个收发错误相互抵消。让 tx_valid 在 ready=0 时保持，验证当前字节发完才接受下一字节。复位中途发送后，重新发一个完整字节应恢复。

提交两个 RTL 文件、sim/tb_uart.sv、ModelSim 执行命令和实测结果。第一天完成字节级仿真，与组长一起检查线路回环。第二天把真实收发模块交给 3 号集成。

## 对接对象

3 号直接提供 tx_valid、tx_data，接收 rx_valid、rx_data。每个 rx_valid 只计一次，每个 TX 握手只接受一次。向组长提交接口保持一致的模块即可。
